## 五、必须先确认的四件事

我不能替你决定，但这些都是**决定材料怎么写**的前提：

### 1. 团队人数与学校
赛道一、二都是**团队赛，1–3 人，必须同校**。
- 你一个人可以报（1 人团队也算团队赛）
- 但**一个人不能同时报赛道一的团队和赛道二的团队**？——需确认是否允许同一个人用不同作品报名多个赛道

### 2. 两个赛道是"两个作品"还是"同一个作品双报"
- 若双报：赛道一需 Web 形态，赛道二需小程序形态，实际上是**两套前端**（后端可共用）
- 建议：**主攻赛道二**（现成），赛道一用 H5 版本 `npm run build:h5` 试试能否跑通

### 3. `智能无感` 是否有"历史"
f 项要求如实说明。参加过其他比赛？已上线？往届作品迭代？

### 4. 小程序主体类型
- **个人主体**：不能开通支付 → "商业闭环"只能讲订阅/广告模式
- **企业主体**：可开通支付 → 商业闭环可写服务费/会员
