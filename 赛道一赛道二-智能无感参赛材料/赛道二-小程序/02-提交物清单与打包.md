# 提交物清单与打包指南

> 两个赛道的提交物差异很大：赛道二交**一个 ZIP**，赛道一交**仓库 + 多个文件**。

---

## 赛道二：单 ZIP 提交

### 命名规则（**严格照抄**）

```
第九届传智杯-AI小程序赛道-<作品名称>
```

例：`第九届传智杯-AI小程序赛道-AI节律守护智能无感`

> 原文：*"命名规则：第九届传智杯-AI小程序赛道-作品名称"*
> 建议扩展名为 `.zip`（原文只说"仅接受 ZIP 格式"）。

### 大小限制

**建议 ≤ 300MB**（原文："大小建议不超过 300MB"）

⚠️ **视频是大头**。5–8 分钟 1080p 视频约 200–500MB。建议：
- 用 H.264 压缩，码率 4–6 Mbps
- 或把视频放网盘，ZIP 内放链接（但**评审可能不方便**，尽量塞进去）

### ZIP 内部结构（推荐）

```
第九届传智杯-AI小程序赛道-AI节律守护智能无感.zip
│
├── 01-作品说明文档.pdf              ← a–g 七项，核心
├── 02-演示视频.mp4                  ← 5–8 分钟 1080p
├── 03-体验说明.md                   ← 账号、二维码、注意事项
├── 04-体验二维码.png                ← 小程序码
├── 05-功能截图/                     ← 15–20 张
│   ├── 01-登录.png
│   ├── 02-节律守护.png
│   └── ...
│
├── 06-源代码/
│   ├── backend/                     ← Java 后端
│   ├── frontend/                    ← uni-app 前端
│   ├── admin/                       ← Vue 后台管理
│   └── db/                          ← 建表脚本
│
└── README.md                        ← 启动说明 + 测试账号
```

> 💡 **为什么分成编号目录**：评委打开 ZIP 后一眼能按顺序看，不会找不到东西。

### 源代码打包注意（**重要**）

**必须排除**：

```powershell
# 在打包前清理
Remove-Item -Recurse -Force -ErrorAction SilentlyContinue `
  frontend/node_modules,
  frontend/dist,
  backend/target,
  admin/node_modules,
  _解压预览

# 排除 .env（只保留 .env.example）
```

**建议用这个打包命令**（PowerShell）：

```powershell
$src  = "D:\msr150174\项目\智能无感"
$stage = "$env:TEMP\czb_submit"
$out   = "D:\msr150174\项目\传智杯\提交包"

New-Item -ItemType Directory -Path $stage -Force  | Out-Null
New-Item -ItemType Directory -Path $out   -Force  | Out-Null

# 复制源码，排除大目录
robocopy "$src" "$stage\06-源代码" /E /XD node_modules dist target _解压预览 .git .obsidian `
  /XF "*.tar.gz" "*.zip" ".env" "*.iml" "dump.rdb" /NFL /NDL /NJH /NJS | Out-Null

"源码已暂存：$stage\06-源代码"
```

然后手动把文档、视频、截图放进 `$stage`，最后压缩：

```powershell
Compress-Archive -Path "$stage\*" `
  -DestinationPath "$out\第九届传智杯-AI小程序赛道-AI节律守护智能无感.zip" `
  -CompressionLevel Optimal
```

## 两赛道通用的"评审友好"设计

评委要在有限时间内看懂你的作品。以下做法能显著提升印象分：

### 1. README 放测试账号

```markdown
## 评审演示账号
- 账号：13800000001
- 验证码：见后端控制台日志（开发模式）
- 或使用固定账号：demo / Demo@2026
```

### 2. 提供"一键体验"入口

```markdown
## 30 秒体验路径
1. 扫码/点击链接
2. 用测试账号登录
3. 首页 → 点击「AI 助手」→ 问"我今天睡眠怎么样"
4. 点击「居家守护」→ 长按 SOS 3 秒 → 观察告警
```

**评委最烦的是"打开后不知道该点哪里"。**

### 3. 视频前 15 秒必须抓住注意力

```
0:00–0:15  直接展示最惊艳的功能
           不要放 logo、不要放"项目介绍"标题页
```

### 4. 在文档里明确标注"对应赛题要求"

例如：

```markdown
### b. 小程序与 AI 能力说明
> 对应赛题要求：明确标注调用的微信小程序能力、云开发能力与 AI 能力

（以下内容...）
```

**评委好对照打分，你就好拿分。**

## 提交前最终检查（两赛道）

### 内容检查

- [ ] 文档 a–g 七项齐全（赛道二）
- [ ] 技术文档 ≤30 页（赛道一）
- [ ] 视频 5–8 分钟（不多不少）
- [ ] 视频分辨率 ≥1080p
- [ ] 视频有声音、有讲解
- [ ] 截图清晰（不要糊）
- [ ] 测试记录是真实数据
- [ ] 历史说明如实填写

### 技术检查

- [ ] 仓库 Public（无痕窗口能打开）
- [ ] 仓库**无任何密钥**（`git log -p | grep -E "pat_|sk-"`）
- [ ] `.env.example` 无真实值
- [ ] `node_modules` 未入库
- [ ] ZIP 内源代码**能独立跑起来**（找台干净电脑测）

### 演示检查

- [ ] 体验版/正式版**已过审**（不是"审核中"）
- [ ] 二维码能扫开
- [ ] 测试账号能登录
- [ ] AI 功能可正常响应
- [ ] **断开 AI 服务后仍能用**（验证三层降级）

### 流程检查

- [ ] 报名已缴费（否则无提交入口）
- [ ] 组别选对
- [ ] ZIP 命名完全符合规则
- [ ] ZIP ≤300MB
