### f. 历史说明

**本项目存在技术迭代历史，非往届参赛作品。**

#### 一、迭代概况

本作品前身为 `ai-rhythm-guardian v3.0.0`（Taro + React 技术栈），经完整重构为当前版本（uni-app + Vue 3 + Spring Boot）。
**重构过程留存了完整的技术分析与决策记录**，可追溯、可验证。

| 项 | 原版本 v3.0.0 | 当前版本 |
|---|---|---|
| 项目名 | ai-rhythm-guardian | AI 节律守护 · 智能无感 |
| 前端 | Taro 4.1.9 + React 18 + Tailwind 4 + Zustand | **uni-app 3.0 + Vue 3 + TypeScript + Pinia** |
| 后端 | NestJS + Supabase（PostgreSQL） | **Spring Boot 3.2.5 + MyBatis + MySQL 8 + Redis** |
| 页面数 | 36 | 36 |
| 接口数 | 136 | **153** |
| 发布状态 | 未发布（游客模式调试） | 见下方"发布计划" |

#### 二、相对原版本的优化部分

本次迭代修正原项目 **14 处缺陷**，并完成 **5 类关键升级**：

##### 2.1 安全问题修复（最重要）

| # | 原问题 | 修正 |
|---|---|---|
| 1 | **Coze Token 硬编码在前端**（`coze.config.ts`、`ai-chat/index.tsx`），编译进小程序包可被反编译提取 | 所有 AI 调用后移到后端，Token 存环境变量，**前端零密钥** |
| 2 | **高德 Key 硬编码在前端** | 同上，改为后端中转 |
| 3 | 密钥同时存在于 `server/.env` | 统一的 `.env` 管理 + `.gitignore` 排除 |
| 4 | `application.yml` 中密钥作为默认值 | 改为空默认值，强制环境变量注入 |
| 5 | 文档中记录了泄露密钥原文 | 全部脱敏处理 |

> 完整的《安全审计报告》随项目提交，记录了全部 5 类泄露点的位置、风险等级与处理方式。

##### 2.2 功能缺陷修复（14 处）

| # | 原问题 | 修正 |
|---|---|---|
| 1 | **跌倒检测 `handleEmergencySOS()` 写在 `if (detected)` 块外 → 每次都弹 SOS** | 移入条件块内，仅在真检测到跌倒时触发 |
| 2 | 首页睡眠评分环右侧三行是**硬编码假数据** | 改为真实数据计算 |
| 3 | 监测页有整套大字模式 CSS **但未挂载** | 挂载 + 增加开关 |
| 4 | 守护页 SOS 界面文案写"3 秒"但代码实际 **1 秒** | 按文案实现 3 秒长按 |
| 5 | 设备/老人状态是**死值**（不随数据变化） | 从真实数据读取 |
| 6 | 配色不统一（蓝/绿混用） | 统一为暖米绿设计系统 |
| 7 | 电话号码硬编码 | 从数据库读取 |
| 8 | catch 分支用闭包旧值 | 取最新值 |
| 9 | 统计口径不一致 → **可能算出负数** | 统一口径 + 边界保护 |
| 10 | `healthScore` 恒为 null | 真实计算 |
| 11 | 账号注销仅提示 toast | 明确提示"功能开发中" |
| 12 | 设置项不持久化 | localStorage 持久化 |
| 13 | 5 处密钥泄露 | 改为后端中转 |
| 14 | `userId: "user_001"` 写死 | 按真实登录用户隔离 |

> 完整的《转换决策记录》随项目提交，逐条记录了问题发现、修正方案与理由。

##### 2.3 AI 能力升级

| 能力 | 原版本 | 当前版本 |
|---|---|---|
| 降级机制 | 单层（Coze 失败即报错） | **三层降级**（Ollama → Coze → 规则库） |
| 规则库 | 无独立实现 | **12 条规则独立兜底**，永远可用 |
| 多模态 | 语音/图像基础调用 | 语音/图像/文本三模态 + **跌倒检测** + 视频帧分析 |
| 语音合成 | 无 | TTS 播报（适老化） |
| 健康报告 | 无 | 日报 / 周报生成 |

##### 2.4 架构升级

| 项 | 说明 |
|---|---|
| 前后端分离 | 明确 RESTful 契约，153 个接口全部覆盖 |
| 一键部署 | `start.bat` 自动检测 MySQL/Redis → 建库建表 → 编译 → 启动 |
| 后台管理 | 新增 Vue 3 独立管理端（6 个视图） |
| 数据层 | PostgreSQL → MySQL（类型逐项转换，12 张表） |

##### 2.5 适老化落地

原项目"设计"了适老化但未真正实现，本版本系统落地：

- 大字号模式（22px 标题 / 64px 按钮高度）**真正挂载并可开关**
- 长按 3 秒 SOS（与文案一致）
- 语音优先输入 + TTS 播报
- 三级字体缩放
