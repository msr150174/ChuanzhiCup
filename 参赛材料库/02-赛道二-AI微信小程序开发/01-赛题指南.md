## 一、一句话看懂这个赛道

主题：**「连接亿级场景 · 激发轻应用创新」**，定位 **AI + 微信生态创新应用**。

核心公式：**微信小程序能力 + AI 能力 + 真实业务场景**，三者结合，并且要能在微信生态里形成**完整产品闭环**——技术方案 + 场景价值 + 用户体验 + **传播设计 + 运营机制 + 商业闭环**。

> 与 Web 赛道最大差异：**这不是纯技术比拼**，非常看重"能不能真的用起来、传得开、赚得到"。

## 四、评分标准（按权重分配精力）

### 评分维度总览

| 维度 | 权重 | 优 | 良 | 中 | 差 |
|---|---|---|---|---|---|
| **技术实现** | **25%** | 22–25 | 18–21 | 12–17 | 0–11 |
| **AI 能力融合** | **20%** | 18–20 | 14–17 | 8–13 | 0–7 |
| **创新设计** | **20%** | 18–20 | 14–17 | 8–13 | 0–7 |
| 场景落地与商业闭环 | 15% | 13–15 | 10–12 | 6–9 | 0–5 |
| 产品体验与用户增长设计 | 10% | 9–10 | 7–8 | 5–6 | 0–4 |
| 完整性与材料质量 | 10% | 9–10 | 7–8 | 5–6 | 0–4 |

### 各维度考察要点

- **技术实现 25%**：是否合理使用微信小程序与微信生态能力、前后端协同顺畅、工程实现与性能稳定性达标
- **AI 能力融合 20%**：是否有效融合大模型、Agent、RAG、AI 工作流或多模态，并且**在业务流程中真实发挥作用**（不是摆设）
- **创新设计 20%**：六维创新综合判断
- **场景落地与商业闭环 15%**：贴近真实业务、有明确用户对象、**转化路径**、运营机制、可持续增长思路
- **产品体验与用户增长设计 10%**：用户路径、交互体验、**传播设计**、**留存机制**、运营思维
- **完整性与材料质量 10%**：可稳定演示、材料完整清晰、关键创新与落地价值**可验证**

> **前三维合计 65%**，是主战场。但注意：15% + 10% + 10% = 35% 给了"落地/增长/材料"——这部分**恰好是小程序赛道最容易拿分的地方**。

## 七、备赛行动清单

### 第 1 阶段：立项（1 周）
- [ ] 组队（≤3 人同校）+ 确认组别
- [ ] 确认 **小程序主体/AppID**（个人号还是企业号？**支付需要企业主体**，早决策）
- [ ] 选定主题方向 + 明确目标用户与转化路径
- [ ] 画出核心流程与页面结构草图
- [ ] 建仓库，开始细粒度 Git 提交

### 第 2 阶段：技术排坑（2–3 周，**越早越好**）
- [ ] 小程序基础框架 + 云开发环境（或自建后端）
- [ ] 打通 **大模型 API**（小程序需注意**域名白名单 / request 合法域名**，云开发可绕过）
- [ ] 接入并验证：登录、分享、**订阅消息**、地图（按需）
- [ ] 落地 AI 能力：RAG 知识库 / Agent 编排 / OCR / 语音
- [ ] **内容安全**接口接入（小程序上审几乎必备）

### 第 3 阶段：产品与运营设计（与开发并行）
- [ ] 写清**六维创新点**
- [ ] 设计**增长闭环**：从哪来（分享/二维码/私域）→ 怎么留（订阅消息/会员）→ 怎么转化（付费/服务）
- [ ] 算一版**商业闭环**：成本（AI API 调用）vs 收入模型
- [ ] 准备**测试记录**（功能测试用例 + 结果）

### 第 4 阶段：上线与验证（1–2 周，**提前排审核**）
- [ ] 提交微信审核 → 配置**体验版**或**正式上线**
- [ ] 留存**审核结果截图、体验二维码、真实数据截图**（加分项）
- [ ] 准备**测试账号**

### 第 5 阶段：材料打包（1 周）
- [ ] 写作品说明文档，**a–g 七项逐条对照，一项不落**
- [ ] 录功能演示视频与关键流程录屏
- [ ] 截图功能界面、关键流程、运行效果
- [ ] 打包 ZIP：`第九届传智杯-AI小程序赛道-作品名称.zip`（≤300MB）
- [ ] 检查：源代码中**无 API 密钥硬编码**

### 第 6 阶段：提交（**提前 3 天以上**）
- [ ] 缴费 → 个人中心获取提交链接 → 上传 ZIP
- [ ] **严禁逾期**（逾期=自动弃权）

## 八、加分 / 避坑提示

**加分**
- 作品**完成体验版配置或正式上线**（凭证、数据、审核结果都能加分）
- 真实用户数据、留存/传播数据截图
- 材料完整且"可验证"（对应 10% 的完整性与材料质量）

**避坑**
- ❌ **不要在最后一周才提审**：微信审核有周期，被驳回要改再审
- ❌ **request 合法域名**没配好 → 线上 AI 接口全挂，务必真机验证
- ❌ **支付能力需企业主体**，个人主体无法开通，早确认
- ❌ AI 能力别做成"贴一个聊天框"，要在业务流程中真实发挥作用（20% 权重）
- ❌ 往届作品一定要在 f 项**明确标注优化部分**，否则有抄袭风险
- ❌ 报名信息作假 / 抄袭 / 内容违规 → 取消资格
