## 二、打包命令（PowerShell，路径按实际调整）

```powershell
$src   = "D:\msr150174\项目\智能无感"
$stage = "$env:TEMP\czb_submit"
$out   = "D:\msr150174\项目\传智杯\提交包"
New-Item -ItemType Directory -Path $stage,$out -Force | Out-Null

robocopy "$src" "$stage\06-源代码" /E `
  /XD node_modules dist target _解压预览 .git .obsidian `
  /XF "*.tar.gz" "*.zip" ".env" "*.iml" "dump.rdb" /NFL /NDL /NJH /NJS | Out-Null

# 手动把 01-05、07、README 放进 $stage 后执行：
Compress-Archive -Path "$stage\*" `
  -DestinationPath "$out\第九届传智杯-AI小程序赛道-AI节律守护智能无感.zip" `
  -CompressionLevel Optimal
```

**必须排除**：`node_modules`、`dist`、`target`、`.env`（只保留 `.env.example`）、`_解压预览`、`.git`、`dump.rdb`、`*.tar.gz`、`*.zip`。

**视频体积**：5–8 分钟 1080p 约 200–500MB，建议 H.264、码率 4–6 Mbps 后再入包，确保 ZIP ≤300MB。

## 三、提交前检查

### 内容
- [ ] a–g 七项齐全，且表述与源码一致（见《02-源码事实校正说明.md》）
- [ ] 截图 15–20 张，清晰、无占位图冒充识别结果
- [ ] 测试记录为**真实执行结果**，无预填 ✅
- [ ] f 项两项事实已由团队确认
- [ ] 视频 5–8 分钟、≥1080p、有讲解
- [ ] 口播与文档均不宣称「三模态视觉识别 / 跌倒自动检测 / ASR / TTS / 订阅消息已推送」

### 技术
- [ ] ZIP 内源码能在干净环境按 README 启动
- [ ] 前端产物与仓库无真实密钥（`pat_` / `sk-` / `AKIA` / 明文 AppSecret）
- [ ] `.env.example` 为全空值模板
- [ ] `src/services/request.ts` 的 `DEV_LAN_IP` 已改为可配置或改为评审环境地址
- [ ] `manifest.json` 的 AppID 已替换为参赛主体真实 AppID
- [ ] `application.yml` 中残留的 `guardian.jwt.*` 若保留，需在文档说明「未使用」

### 演示
- [ ] 体验版/正式版**已过审**（非审核中），二维码可扫
- [ ] 测试账号可登录
- [ ] Coze Token / Ollama 已配置，AI 功能可正常响应
- [ ] 断开外部 AI 后仍能用（验证三层降级，展示 `provider=rule`）

### 流程
- [ ] 报名**已缴费**、提交入口已获取
- [ ] 组别正确、团队 1–3 人同校
- [ ] ZIP 命名完全符合规则
- [ ] ZIP ≤300MB
- [ ] 提交后不得修改 —— 最后 30 分钟只检查
