## 二、共性：四个赛道**都要交**的东西

四份材料几乎通用，只是细节不同：

### 1. 代码仓库
- 平台：**GitHub / Gitee**，必须 **Public** 或给评审开权限
- 结构清晰、有效注释、主流规范
- README：项目介绍、技术架构、安装运行指南、**团队信息**
- **完整 Git 提交历史**（体现真实开发过程）
- 环境配置：`.env.example` + 依赖清单
- 🚫 **仓库里绝不能有 API 密钥**

### 2. 演示视频
- **5–8 分钟**（③ 额外要求含 ≥2 分钟 AI 协同过程）
- **MP4，≥1080p**
- 普通话讲解，可配字幕
- 内容：项目介绍 + 核心功能演示 + AI 技术亮点

### 3. 技术文档
- **PDF，≤30 页**
- 通用章节：项目概述、需求分析、系统架构设计、AI 技术方案、核心功能实现、测试与部署、总结与展望
- **必须有**：AI 技术选型理由 / 集成方式 / 优化策略
- **必须有**：技术创新点 + 应用创新点

## 三、共性：**最重要的三个硬约束**

### ⏰ 1. 时间
| 事项 | 时间 |
|---|---|
| 报名 + 缴费 | 即日起 — **2026-11-18** |
| **省赛作品提交截止** | **2026-11-18** |

| 国赛报名 | 2026-12-10 — 12-21 |

> ⚠️ 小程序赛道明确：**逾期未提交视为自动弃权**，且各赛段截止前 3 天官方社群会同步进度。

### 💳 2. 必须**先缴费**
> 四个赛道都写明：**省赛作品提交入口需完成缴费后**，登录赛事个人中心 → 所报赛项处查看，**不再单独提供外部链接**。

**没缴费 = 拿不到提交入口 = 无法提交。这是最容易踩的坑。**

### 🎯 3. 组别选对
| 组别 | 适用对象 | 可选组别 |
|---|---|---|
| 研究生组 | 研究生 | 只能研究生组 |
| A 组 | 985/211 本科生 | A / 研究生组 |
| B 组 | 非 985/211 普通本科 | B / A / 研究生组 |
| C 组 | 高职高专 | C / B / A / 研究生组 |

> **选错组别 = 无条件取消参赛资格及所有成绩。** 报名前先查清自己学校的层次。

## 四、共性：奖项与晋级（四赛道一致）

### 省赛（复赛）
| 奖项 | 比例（≤本省参赛人数） | 晋级 |
|---|---|---|
| 一等奖 | 10% | ✅ 晋级国赛 |
| 二等奖 | 20% | ✅ 晋级国赛 |
| 三等奖 | 30% | ✅ 晋级国赛 |
| 优秀奖 | 30% | — |

- 赛区：**北部 / 东部 / 南部 / 西部 / 港澳台 / 境外**
- 各赛区内**按科目/组别**分别评审排名
- 一二三等奖合计 **60%** 可晋级，**通过省赛的门槛其实不算高**

### 国赛（决赛）
| 奖项 | 比例（≤） |
|---|---|
| 一等奖 | 5% |
| 二等奖 | 20%（③④页面另处写 25%）|
| 三等奖 | 35%（③④页面另处写 30%）|
| 优秀奖 | 40% |

### 获奖资格核心要求
- **零分卷不得奖**
- 获奖比例仅作参考，**不构成最终承诺**
- 组委会会划定各奖项**最低分数线**，未达线不参与该奖项评选
- 比例调整权归主办方

### 指导教师
指导队伍获决赛一二三等奖 → 颁发**"优秀指导教师"证书**。
（① ② 团队赛每队 ≤2 名指导老师；③ ④ 个人赛页面未列指导老师名额）

## 六、怎么选？（决策建议）

### 按身份
| 你的情况 | 推荐 |
|---|---|
| 有好队友、擅长前端 | ① AI WEB 网页开发 |
| 有好队友、想做能传播的产品 | ② AI 微信小程序 |
| 单人作战、想快点出成果 | ③ Vibe Coding |
| 单人作战、AI/算法底子硬、有科研经历 | ④ 科研 Agent |

### 按风险
| 赛道 | 主要风险 |
|---|---|
| ① Web | AI 技术深度是硬仗，35% 权重；API 费用自担 |
| ② 小程序 | **微信审核周期**、request 域名白名单、支付需企业主体 |
| ③ Vibe Coding | **过程留痕**：从第一天没留 Prompt 记录，后期补不回来 |
| ④ 科研 Agent | **工作量最大**：六大模块 + 官方测试用例，还有必交的在线演示 |

### 一句话总结
- ① **拼"AI 用得深不深"**
- ② **拼"产品能不能落地、传得开"**
- ③ **拼"过程能不能被验证"**
- ④ **拼"系统做得全不全、稳不稳"**
