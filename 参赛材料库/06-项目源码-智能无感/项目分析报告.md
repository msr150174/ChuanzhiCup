## 四、🔴 安全风险（**必须处理**）

### 风险 1：硬编码 Coze API Token（严重）

**位置**：`dist/pages/ai-chat/index.js`

```js
const f = {
  botId: "7637945513727672363",
  token: "pat_***REDACTED***",
  baseUrl: "https://api.coze.cn",
  userId: "user_001",
  timeout: 3e4,
  stream: !1,
  offlineMode: !1
};
```

**风险**：

| 项 | 说明 |
|---|---|
| **Token 明文** | 编译进小程序包，**任何人反编译即可获取** |
| **PAT 类型** | `pat_` 前缀是 **Personal Access Token**，权限范围大 |
| **可被滥用** | 他人可用你的 token 调 Coze，**消耗你的额度/费用** |
| **botId 泄露** | `7637945513727672363` 也被暴露 |

**小程序包本质上不是安全的** —— 用户可以下载 `.wxapkg` 并反编译。

### 风险 2：userId 写死

```js
userId: "user_001"
```

**所有用户共用一个 userId** —— Coze 侧无法区分不同用户，会话会串。

### 风险 3：AppID 是游客模式

```json
{ "appid": "touristappid" }
```

**无法正式发布**，需要注册真实小程序 AppID。

### 风险 4：Coze 域名是开发环境

```
https://322f437a-...dev.coze.site
```

**开发域名可能随时失效**。
