> 当前只有 Taro 编译产物（`dist/`），无法维护。
> 本文给出**恢复成可维护工程**的完整方案。

---

## 一、为什么必须恢复源码

| 问题 | 只有产物的后果 |
|---|---|
| 无法改功能 | 改 `.js` 产物 = 手工改编译结果，改一次崩一次 |
| 无法升级依赖 | 不知道原本用什么版本 |
| 无法协作 | 没人能读 218 KB 的 `taro.js` |
| Token 无法安全处理 | 必须改源码才能把密钥移到后端 |
| 无法上架 | `touristappid` + 开发域名 |

**结论：产物只能用来"看效果"，不能用来"做产品"。**

## 四、关键代码骨架

### 4.1 `src/services/request.ts`（**最重要**）

产物的 `common.js` 里后端地址**硬编码在编译结果**里，恢复后必须外置：

```ts
import Taro from '@tarojs/taro'

/**
 * 网络请求封装
 *
 * ★ 安全要点：
 *   1. 后端地址从环境变量读取，不硬编码
 *   2. 绝不在这里放任何第三方 API Token
 *   3. 所有需要密钥的调用都走后端中转
 */

const BASE_URL = process.env.TARO_APP_API_BASE || 'https://your-domain.com'

interface RequestOptions {
  url: string
  method?: 'GET' | 'POST' | 'PUT' | 'DELETE'
  data?: Record<string, unknown>
  header?: Record<string, string>
}

/** 拼接完整地址（绝对地址原样返回） */
function resolveUrl(url: string): string {
  if (/^https?:\/\//.test(url)) return url
  return `${BASE_URL}${url}`
}

export async function request<T = unknown>(options: RequestOptions): Promise<T> {
  const res = await Taro.request({
    url: resolveUrl(options.url),
    method: options.method || 'GET',
    data: options.data,
    header: {
      'Content-Type': 'application/json',
      ...options.header
    },
    timeout: 30000
  })

  if (res.statusCode < 200 || res.statusCode >= 300) {
    throw new Error(`请求失败: HTTP ${res.statusCode}`)
  }

  return res.data as T
}

/** 文件上传（语音、图像用） */
export async function uploadFile(
  url: string,
  filePath: string,
  name = 'file',
  formData?: Record<string, string>
) {
  const res = await Taro.uploadFile({
    url: resolveUrl(url),
    filePath,
    name,
    formData
  })

  if (res.statusCode < 200 || res.statusCode >= 300) {
    throw new Error(`上传失败: HTTP ${res.statusCode}`)
  }

  return JSON.parse(res.data) as unknown
}

export const Network = { request, uploadFile }
```

### 4.2 `src/services/ai.ts`（**Token 处理示范**）

**产物的做法（危险）**：

```ts
// ❌ 绝对不要这样做
const config = {
  botId: '7637945513727672363',
  token: 'pat_bLAARa12...',      // 泄露
  baseUrl: 'https://api.coze.cn',
  userId: 'user_001'             // 写死
}
```

**正确做法**：

```ts
import { request } from './request'

/**
 * AI 对话
 *
 * ★ Coze Token 保存在后端，小程序只调用自己的后端。
 *   原因：小程序包可被反编译，任何内置密钥都会泄露。
 */
export async function chat(message: string, conversationId?: string) {
  return request<{ content: string; conversationId: string }>({
    url: '/api/ai/chat',
    method: 'POST',
    data: { message, conversationId }
  })
}
```

**后端负责调 Coze**（Token 存服务端环境变量）：

```
小程序  ──>  你的后端  ──(带 Token)──>  Coze API
         （无密钥）      （密钥在此）
```

### 4.3 `src/utils/storage.ts`

对齐产物里的 6 个存储键：

```ts
import Taro from '@tarojs/taro'

export const STORAGE_KEYS = {
  USER_SETTINGS: 'userSettings',
  CHECK_IN: 'checkInRecords',
  ALERTS: 'alertMessages',
  CHAT: 'chatMessages',
  SOS: 'sosRecords',
  USER_INFO: 'userInfo'
} as const

export function getStorage<T>(key: string, fallback: T): T {
  try {
    const v = Taro.getStorageSync(key)
    return (v === '' || v === null || v === undefined) ? fallback : (v as T)
  } catch {
    return fallback
  }
}

export function setStorage(key: string, value: unknown): void {
  try {
    Taro.setStorageSync(key, value)
  } catch (e) {
    console.error('[storage] 写入失败:', e)
  }
}
```

## 五、备选方案：改用 uni-app + Vue

**如果想和"智跑校园"统一技术栈：**

| 维度 | Taro（重建） | uni-app（重写） |
|---|---|---|
| 语言 | React + TS | Vue 3 + TS |
| 与现有项目一致 | ❌ | ✅ 与智跑校园一致 |
| 迁移成本 | 中 | 中高 |
| 可复用产物逻辑 | 高 | 中（要翻译） |

**如果你打算长期做小程序，我建议 uni-app** —— 两个项目技术栈统一，维护成本低。

## 八、安全检查清单

上线前必须逐项确认：

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 小程序包内无 API Token | 全文搜索 `pat_`、`sk-`、`Bearer` 无结果 |
| 2 | 无硬编码 AppSecret | 同上 |
| 3 | 后端地址用 HTTPS | 不能用 `http://` |
| 4 | 后端地址在域名白名单 | 微信后台配置 |
| 5 | AppID 是真实的 | 不是 `touristappid` |
| 6 | 敏感操作需登录态 | SOS、健康数据 |
| 7 | 用户数据隔离 | 不能所有用户共用 `user_001` |
| 8 | 上传文件大小限制 | 防止恶意大文件 |
| 9 | 接口有频率限制 | 防止刷接口 |
| 10 | 错误信息不泄露内部细节 | 不返回堆栈 |
