## 四、数据用 mock

**页面里的数据都是本地 mock**，纯用来调界面：

```ts
const __state = reactive({
  // 打卡记录
  checkInRecords: [
    { date: '2026-06-20', sleepTime: '23:10', wakeTime: '06:40', duration: 7.5 },
    { date: '2026-06-21', sleepTime: '22:45', wakeTime: '06:30', duration: 7.75 }
  ],
  // 天气
  weather: { temp: 25, text: '晴', humidity: 60, wind: '微风' },
  // 今日活动
  activity: { steps: 6820, distance: 4.8, calories: 265 }
})
```

**这样设计时不会被后端拖住。** 后续接真接口时替换成 HTTP 请求即可。

## 五、已修正的原项目缺陷

转写过程中修正了分析报告发现的 **6 处问题**：

| # | 原问题 | 修正 |
|---|---|---|
| 1 | home 睡眠评分环右侧三行是**硬编码假数据** | 改为 `computed` **真实计算** |
| 2 | monitor 跌倒检测 `handleEmergencySOS()` 写在 `if (detected)` **块外** | **移进块内**，只在真跌倒时触发 |
| 3 | monitor 有整套 `.elder-mode` 大字模式 CSS **但未挂载** | **挂载并做开关** |
| 4 | guardian SOS 界面写"3秒"但代码实际 **1秒** | **按 3 秒**实现 |
| 5 | guardian `deviceStatus`/`elderStatus` 是**死值** | 放入 reactive + 定时器让数据真实变化 |
| 6 | 配色不统一 | **统一暖米绿系** |

**2.vue 另外修正 6 处**：电话号码硬编码、catch 闭包旧值、统计口径负数、healthScore 恒 null、账号注销占位、设置项持久化。

## 六、保留的真实业务规则

这些是原项目**真实的算法**，照抄保留：

### 睡眠时长评分（4 档）

```
7-9 小时  → min(95 + (h-7)*2, 100)   最优
6-7 小时  → 70 + (h-6)*20             一般
> 9 小时  → 80                        过长
< 6 小时  → max(50, h*10)             不足
```

### 健康评分权重

```
作息规律 30% + 用药依从 25% + 运动量 20% + 饮食均衡 15% + 监测异常 10%
```

### 用药时段划分

```
hour < 12  → 早晨
hour < 18  → 午后
else       → 睡前
```

### SOS 触发

```
长按 3 秒 → 倒计时 3 秒 → 触发
松开 → 取消
```

### 权限级别

```
设某个家属为「主要监护人」
  → 全开 6 项权限
  → 其他 active 成员批量降级为 limited
```

## 八、注意事项

### ① 这是设计源码，不是最终产品

- 数据是 mock，**不连后端**
- 图标是 emoji，正式开发时可换 SVG
- 硬件能力（录音/拍照）是**模拟**的

### ② 未在浏览器中实际渲染验证

**校验覆盖的是语法与结构**（标签配对、括号配对、TS 语法），
**不是视觉效果**。建议在 VTJ 里导入后实际预览一次。

### ③ 部分功能是占位

以下功能在原项目里也是占位，新版保持了这一状态并**明确标注**：

| 功能 | 状态 |
|---|---|
| ASR 语音识别 | 占位（弹提示） |
| TTS 语音合成 | 占位（弹提示） |
| 微信登录 | 占位（需真实 AppID） |
| 账号注销 | 占位（提示联系客服） |
