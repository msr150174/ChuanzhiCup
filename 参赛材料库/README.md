## 三条铁律（全赛道通用）

1. **无出处则答「现有资料未覆盖」**
   事实只能来自已入库内容，检索不到就明说，禁止用模型内建知识补。

2. **二手不得标注为原文**
   可信度分级必须如实标注。

3. **仓库中不得出现任何密钥**
   四个赛道原文均有此要求，违规风险最高。
