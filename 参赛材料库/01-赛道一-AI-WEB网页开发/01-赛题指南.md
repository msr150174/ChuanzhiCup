## 一、一句话看懂这个赛道

围绕主题 **「智启未来：AI 驱动的 Web 应用创新挑战」**，用主流前端框架（React/Vue 等）结合 **LLM、AI Agent、RAG、多模态 AI**，做出一个 **AI Native 的 Web 应用**。

关键词：**AI 是核心功能，不是附加的"加个聊天框"**。

## 五、技术栈准备清单（推荐，非强制）

### 前端框架（择一）
- React + Next.js 14+ —— **首选**（App Router、Server Components、API Routes、流式渲染）
- Vue 3 + Nuxt 3 —— 渐进式 / 内容型平台
- Svelte 5 + SvelteKit —— 极致性能
- React + Vite —— 轻量 SPA
- Astro —— 内容驱动、零 JS

### UI 与样式
- **Tailwind CSS**（强烈推荐）、shadcn/ui、Ant Design / Element Plus
- Framer Motion / GSAP（动画）、Three.js / React Three Fiber（3D）

### 前端 AI 集成（补分关键）
- **Vercel AI SDK** —— 流式对话、Tool Calling、生成式 UI（首选）
- LangChain.js —— 浏览器端链式调用、轻量 Agent
- Transformers.js / WebGPU / ONNX Runtime Web —— **端侧推理（技术前瞻性加分）**
- Web Speech API、MediaPipe —— 语音与视觉

### AI 模型接入
- LLM：OpenAI、Claude、Gemini、智谱 AI、DeepSeek
- 多模态：GPT-4o、Gemini Pro Vision、通义千问 VL
- 图像：DALL·E 3、Stability AI ｜ 语音：Whisper、TTS

### 状态与数据
- Zustand / Jotai / Pinia、TanStack Query、IndexedDB、WebSocket / SSE

### 工程工具
- Cursor / Copilot / Windsurf（AI 编程）、Figma / v0.dev（原型）
- Git + GitHub/Gitee、**pnpm**、ESLint + Prettier + **TypeScript**

## 六、选题建议（10 个官方方向）

1. AI Agent 智能助手（自主规划、工具调用、多轮对话）
2. RAG 知识问答系统（向量库 + 检索增强）
3. 多模态 AI 创意平台（文/图/音/视生成与编辑）
4. AI 协同办公工具（写作、纪要、文档分析）
5. AI 教育与学习平台（个性路径、智能出题）
6. AI 健康与生活服务
7. AI 代码开发辅助（代码审查、文档生成）
8. AI 数据分析与可视化（自然语言查询分析）
9. AI 安全与内容治理（内容检测、AIGC 识别）
10. AI 社交与社区应用

**选题红线：**
- 必须原创，**禁止直接拿开源项目包装**
- 必须是 Web 应用形态（PC 端 / 移动端 Web 均可）
- **AI 必须是核心而非附属**，禁止只是套壳调 API
- 鼓励真实问题、社会价值、可落地性

## 八、加分 / 避坑提示

**加分**
- 浏览器端推理（WebGPU / Transformers.js）能体现技术前瞻性
- AI 交互细节（流式、思考可视化、错误边界）直接对应 3% 分值
- 在线演示属"可选加分项"，能上就上

**避坑**
- ❌ 用商用 AI API 的费用**自行承担**，提前规划用量、用免费额度
- ❌ 后端只做"AI 能力接入层"，别把精力堆在后端架构上（本条赛道后端不是重点）
- ❌ 用 AI 编程工具可以，但**必须能解释所有代码逻辑**
- ❌ 涉及用户数据要合规、做隐私保护
- ❌ 报名信息作假、抄袭、内容不健康 → 直接取消资格
